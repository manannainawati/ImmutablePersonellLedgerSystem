📐 Enterprise Blockchain Architecture — 7 Defense Layers

How the Hyperledger Fabric separation of concerns guarantees integrity, non-repudiation, and privacy.

L1

Integrity — BLAKE3 Domain-Keyed Block Chaining

Every block links to the previous block via BLAKE3(core_fields, key=DOMAIN_KEY).

L2

Consensus — Proof of Authority (PoA)

Blocks are valid ONLY if signed by a registered official's Ed448 private key.

L3

Authenticity — Ed448 Digital Signatures (RFC 8032)

Officials sign transactions client-side on their own hardware.

L4

Confidentiality — Fernet Payload Encryption (AES-128-CBC)

Personnel records are symmetrically encrypted at rest.

L5

World State — State Root Commitment

State Root Hash committed to each block header guarantees database convergence.

L6

Transaction Set — BLAKE3 Binary Merkle Trees (SPV Proofs)

Lightweight audit proofs verified in $O(\log N)$ sibling hashes.

L7

Privacy Vault — Zero-Knowledge Range & Attendance Compliance (ZKP)

Proves compliance mathematically without disclosing personal timestamps.
